# ADR-001: Room Sceneの追加分離を現時点では行わない

- Status: Accepted
- Date: 2026年11月5日

## Context

`room_page.dart` は複数のPresentation責務を抱えていたため、P2として段階的な分離を実施した。

Step 1では `RoomRearrangeOverlay` を分離し、Step 2では `RoomFurnitureLayers` を分離した。

再Audit時点では `room_page.dart` は1,943行まで縮小したが、`_RoomBackgroundLayers` は45個のrequired引数を持つ。

## Options considered

1. Step 2でP2完了とする
2. Room Sceneを別Widgetへ分離する
3. Room SceneとTutorial effectsをさらに分離する

## Decision

P2はStep 2で完了とし、Room Sceneの追加分離は現時点では行わない。

## Rationale

- Furnitureとrearrangeのgeometry / hit testという高リスクなPresentation責務はすでに分離できた
- Sceneを別ファイルへ移しても45引数は解消しない
- AnimationControllerのownershipも改善しない
- Room全体のz-orderを一か所で確認できる利点がある
- 追加分離を必要とする具体的な機能変更が現時点ではない
- ファイル行数を減らすだけのrefactorはMVP方針に合わない

## Consequences

### Positive

- 現在の安定したStack構造を維持できる
- 不要なprops drillingやcallback増加を避けられる
- 次versionの機能開発へ進める

### Negative

- `room_page.dart` は依然大きい
- `_RoomBackgroundLayers` の45引数は可読性上の負債として残る
- Letter / tutorial / Weatherのorchestrationは同じStateに残る

## Revisit when

- Room Stackへ3種類以上の新しいvisual layerを追加する
- tutorial visualを大幅に再設計する
- Letter arrival animationを複数パターン化する
- `_RoomBackgroundLayers` の引数がさらに増える
- Stack順やhit testの回帰が繰り返す
- Scene変更のたびにRoomPage統合テストを大量修正する状態が続く
